# 🛒 E-Commerce SQL Data Analysis

> **SQL Data Analytics Project | MySQL | E-Commerce Database Analysis**

A structured SQL project designed to analyze an e-commerce database using practical SQL queries.

The project progresses from basic SQL fundamentals to advanced querying techniques, including filtering, aggregation, multi-table joins, subqueries, and set operations.

---

## 📌 Project Overview

This project uses a small e-commerce database containing multiple related tables.

The analysis focuses on customers, products, orders, order items, payments, and product reviews.

The objective is to use SQL to retrieve, transform, summarize, and analyze relational data to answer practical business questions.

---

# 🎯 Project Objectives

- Analyze customer information.
- Explore the product catalog.
- Analyze orders and sales.
- Calculate revenue and average order value.
- Analyze customer purchasing behavior.
- Analyze product categories.
- Examine payment methods.
- Use joins to combine information from multiple tables.
- Use subqueries for advanced analysis.
- Apply set-based SQL logic.
- Practice SQL from fundamentals to advanced concepts.

---

# 🗄️ Database Schema

The project uses six related tables:

| Table | Description |
|---|---|
| `customers` | Customer names, emails, phone numbers and contact details |
| `products` | Product catalog, categories, prices and stock |
| `orders` | Customer orders, order dates and total amounts |
| `order_items` | Products included in orders, quantities and item prices |
| `payments` | Payment records, payment methods and amounts |
| `product_reviews` | Customer reviews associated with products |
